INTRODUCTION                                                        *legate*

Legate is a Neovim-native Agent Client Protocol client with a shared Markdown
chat buffer, named adapters, local sessions, approvals, filesystem handlers,
and native or Terminalia-backed terminal execution. Neovim 0.11 or newer is
required.

==============================================================================
SETUP                                                      *legate-setup*

>lua
    require('legate').setup({
        default_adapter = 'codex',
        adapters = {
            codex = {
                command = { 'codex-acp' },
                auth_method = 'chatgpt',
            },
        },
    })
<

The adapter command is not bundled. `terminal_backend` defaults to "native";
use "terminalia" only when terminalia.nvim is installed.

==============================================================================
COMMANDS                                                *legate-commands*

*:LegateChat*               Open the shared chat buffer.
*:LegateNewSession*         Create a local session.
*:LegateLoadSession*        Bind or reload a local session.
*:LegateSessions*           List local sessions.
*:LegateSelectSession*      Select a local session.
*:LegateSelectAdapter*      Select a configured ACP adapter.
*:LegateSubmit*             Submit or queue the editable prompt.
*:LegateSteer*              Steer the active turn.
*:LegateInterrupt*          Interrupt the active turn.
*:LegateApprovals*          Inspect approval history.

See the README for the complete command list.

==============================================================================
SECURITY                                                *legate-security*

ACP peers can request file and process operations. Legate confines filesystem
operations to configured roots, requires explicit permission decisions, and
bounds request and terminal lifetimes. Review adapter commands and approval
policy before connecting an untrusted peer. See `docs/security.md`.
